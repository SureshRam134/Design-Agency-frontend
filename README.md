#  Creative Design Agency

A modern and responsive Design Agency website built with Next.js, React, Tailwind CSS, and Framer Motion.

##  Features

- Responsive Design
- Modern Hero Section
- Services Section
- Portfolio with Dynamic Popup
- Contact Form with Validation
- Smooth Animations
- SEO Metadata

##  Tech Stack

- Next.js
- React.js
- Tailwind CSS
- Framer Motion
- Lucide React
- React Hot Toast

##  Installation

### 1. Go to the project folder

```bash
cd design-agency
```

### 2. Install required packages

```bash
npm install framer-motion
npm install lucide-react
npm install react-hot-toast
```

### 3. Run the project

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
